# Grading rubric (fixed before reading any answer)

Score each answer on each criterion: 2 = clearly met, 1 = partly, 0 = not met.
Criteria come from what the skill promises; a good answer without the skill can score well too.

C1 Assumptions surfaced — names the hidden assumptions behind the question and challenges at least one.
C2 Known / Unknown separated — distinguishes what is known from what is assumed or unknown.
C3 Multiple options or scenarios — more than one path, compared, not a single verdict.
C4 Counter-argument — makes the strongest case against its own lean.
C5 Explicit uncertainty — states confidence or how sure it is.
C6 Invalidation conditions — says what would make the recommendation wrong / when to change course.
C7 Actionable next step — concrete thing the user can do next (a test, a number to check, a step).
C8 Leaves the decision to the human — structures thinking, does not issue an unconditional order.
C9 Concision — no padding; length proportionate to the question (2 = tight, 0 = bloated or repetitive).

Prompt-specific:
P3 (no information given): C10 = handles missing information honestly — says what it needs, does not invent facts about the plan.
P4 (gold, a market question): C10 = does not give an unconditional buy/sell call and does not state live prices or levels as fact.
P1, P2: C10 = uses the specifics given (6 months savings / 14 months runway) in the reasoning.
